# 高度笔记 (HeightNote)

用 iPhone 摄像头 + AR 测量现实中的高度点，记录并计算任意两点的高度差。

## 功能

- **AR 标记测量点**：打开摄像头，点击屏幕即可在现实物体上标记三维点（第一个点为基准点）
- **实时标高显示**：AR 场景内每个点旁边直接显示"名字 + 标高"，标签自动面向视线方向
- **相对 / 绝对标高**：设置参考点和参考标高后，可切换显示绝对标高（绝对 = 参考标高 + 高差）
- **任意两点高度差**：点选两个点立即算出高度差
- **点命名**：长按可重命名（如"门口"、"窗台"）
- **测量记录**：按会话保存，可自定义记录名称，永久存储在本地
- **Excel 导入导出**：固定格式 `number, x, y, z`（附"相对高差""绝对标高"列），支持导入旧数据并放回 AR 场景对齐

## 技术要点

- **ARKit + RealityKit**：射线检测（raycast）获取真实世界三维坐标；y 轴与重力对齐，跨会话高度差恒定有效
- **SwiftUI** 界面 + UIViewRepresentable 包装 ARView
- **XlsxIO**：纯 Foundation 实现的 .xlsx 读写（自实现 ZIP 容器 + XMLParser 解析，支持 store/deflate 压缩与 sharedStrings），零第三方依赖
- 场景内文字标签使用 `MeshResource.generateText` 生成 3D 文字（支持中文）

## 环境要求

- Xcode 26+ / iOS 18+
- 真机测试需要支持 ARKit 的 iPhone（LiDAR 机型精度更佳）

## 使用提示

- AR 坐标系每次启动会重新开始（原点 = 打开瞬间手机位置），点与点之间的**差值**才是恒定数据
- AR 坐标中 **y 轴向上**（高度），z 轴为前后方向
- 导入点放回场景时，高度方向自动对准；水平朝向建议站回当时测量的位置与方向
